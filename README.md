# absorption-intensity
These data provide estimates of absorption intensity, which was developed in my joint work with M. Deniz Yavuz. Measuring Firms' Capability to Absorb External Knowledge. Journal of Financial Economics, 183, September 2026. These data span 1950 through 2023. 

If you use these data, please cite my paper as the data source. 


| Variable       | Description                        |
| -------------- | ---------------------------------- |
| permco         | CRSP PERMCO                        |
| year           | Year extracted from datadate       |
| absorption_3   | Absorption intensity (3-year)      |
| absorption_5   | Absorption intensity (5-year)      |
| absorption_10  | Absorption intensity (10-year)     |

These data span 1950 through 2023 and include three different versions of absorption intensity for firms in CRSP/Compustat. As described in the above mentioned paper, absorption intensity is a function of patent grants and patent citations. I plan on updating these data on an annual basis.
